## 这里的文档不是当前事实

本目录保留被后续文档取代的实现说明。它们**不再随代码更新**，读它们只为一个目的：
追溯当时为什么那样设计。任何与现行文档或源码冲突的地方，以现行文档和源码为准。

每篇开头都有一条取代声明，指向接替它的现行文档。

## 为什么保留而不是删除

`docs/README.md` 的维护规则第 2 条：不删除有决策价值的旧稿，移动到历史目录并标明它
不是当前事实。删掉的话，“当初为什么不这么做”就只能靠翻 git 历史回答了。

## 什么时候该往这里加东西

当两篇现行文档开始描述同一件事时。判据不是“旧”，是**重复**——重复会让读者
在两个说法之间猜，而猜错的代价由代码承担。把被取代的那篇移进来，加上取代声明，
并把指向它的链接改到接替者。
